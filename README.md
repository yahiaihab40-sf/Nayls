# Nayls

Egyptian-themed storefront for Nayls press-on nails. A single self-contained page: open `index.html` or serve it with GitHub Pages.


A renewed version lives in `v2/` (served at /Nayls/v2/): a photo-led product page with the 16 designs, an email order form with prices in EGP, and the hieroglyph name tool. Its photographs are licensed stand-ins from Wikimedia Commons, credited in `v2/credits.html`.
